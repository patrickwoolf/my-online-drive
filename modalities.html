二、冷療與水療(Cold & Hydrotherapy)

儀器名稱能量傳遞機制作用深度適應症禁忌症 / 注意事項
冷療 / 冰敷Cold Pack / Ice Massage傳導 / 蒸發表淺至中層
  • 急性運動傷害與發炎期(24–72 小時內止血、消腫、止痛)
  • 急性關節炎發作(抑制滑膜膠原酶活性)
  • 降低肌張力亢進 Spasticity(中風、多發性硬化症)
  • 雷諾氏現象、冷過敏(冷蕁麻疹)
  • 冷凝球蛋白血症、陣發性冷血紅素尿症
  • PVD、感覺喪失
  • 開放傷口、周邊神經修復區
冷熱交替浴Contrast Bath血管交替收縮與擴張(Pump effect)肢體末端表淺
  • 亞急性/慢性肢體腫脹與組織液滯留
  • 複雜性區域性疼痛症候群(CRPS / RSD)
  • 自主神經調節失調、高血壓輔助調節
  • PVD、感覺喪失
  • 開放傷口、急性發炎
  • 嚴重心血管疾病
水療桶 / 哈伯氏桶Whirlpool / Hubbard Tank對流 / 浮力 / 靜水壓全身或局部表淺
  • 大面積燒燙傷與慢性潰瘍(清創、去痂皮與清潔)
  • 下肢關節炎不便負重者(浮力水中運動)
  • 痔瘡、產後疼痛(溫水坐浴 Sitz bath)
  • 嚴禁於水中使用市電電療(致命電擊)
  • 嚴重心肺疾病、發燒
  • 大小便失禁、急性 DVT
  • 需隔離之感染傷口、水溫過高

五、【金屬】與【水/濕氣】關鍵禁忌與安全規範

專科考試與臨床實務高頻考點

治療儀器金屬 / 體內植入物水 / 汗水 / 濕氣
短波 SWD絕對禁忌("No Metal"):感應電流與金屬反射會在金屬旁引發嚴重深部燒傷。嚴禁汗水/水珠:電磁場集中,導致皮膚點狀燙傷;需墊乾毛巾吸汗。
微波 MWD絕對禁忌:金屬強烈反射與聚熱引發組織高熱壞死。嚴禁水泡/積液/水腫:微波極易被水分子吸收產生劇熱。
超音波 US金屬非絕對禁忌(散熱快),但嚴禁塑膠/PMMA 骨水泥(高吸收率會熔化)。水泡法(間接法)需使用去氣泡水,避免氣泡反射聲波。
電療 TENS/IFC/FES嚴禁於心律調節器/ICD/SCS 等電子植入物附近(信號干擾);骨釘鋼板可用。嚴禁於水療池中施加市電電療(預防致命電擊)。
紅外線 IR可安全用於體內鋼板/骨釘;但需移去體表金屬飾品/鈕扣防止表面過熱。患部大量汗水應擦乾;非接觸特性適合無法承受重壓的表淺傷口/乾燥處置。
微粒治療無特殊金屬過熱禁忌。嚴禁開放性濕潤傷口,避免粉塵沾黏與交叉感染。
